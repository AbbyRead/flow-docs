Getting started

A form is a menu that is shown to a player. It is made of elements (also called widgets), such as labels, buttons, text fields, and inventory slots, which are arranged by layout elements like gui.VBox. You describe a form with a build function that returns the elements, and flow works out the positions and sizes and shows the form for you. See Elements for what each element does.

Basic example

See example.lua for a more comprehensive example which demonstrates how layouting and alignment works.

local gui = flow.widgets -- local recommended for direct referencing
local STARTING_SELECTION = 3 -- change and rerun to see the difference

local function build_vbox(player_obj, ctx)
    return gui.VBox {
        gui.Label {label = "Here is a dropdown:"},
        gui.Dropdown {
            name = "cool_dropdown",
            items = {'First item', 'Second item', 'Third item'},
            index_event = true,
            selected_idx = ctx.value or 1
        },
        gui.Button {
            label = "Get dropdown index",
            on_event = function(player, ctx)
                local idx = ctx.form.cool_dropdown or ctx.value or 1
                core.chat_send_player(player:get_player_name(),
                    ("You have selected item #%d!"):format(idx))
            end,
        }
    }
end

local form = flow.make_gui(build_vbox)
local player_obj = core.get_player_by_name("playground")

form:show(player_obj, {value = STARTING_SELECTION}) -- second argument is optional

Updating forms

If some data displayed inside a form changes (for example a timer or progress indicator), you can use form:update to update the form without resetting ctx or showing the form again if the player has closed it.

Luanti has no way to change a form that is already open, so flow has to show the whole form again. Because of this, players may lose text typed into fields that hasn't been sent to the server (which happens when they press a button or Enter) when form:update is called.

-- Re-shows the form for one player if they have the form open
my_gui:update(player)

-- Re-shows the form for all players that have the form open and where
-- ctx.test == 123
my_gui:update_where(function(player, ctx)
    return ctx.test == 123
end)

-- Re-shows the form for all players with the "server" privilege
my_gui:update_where(function(player, ctx)
    return core.check_player_privs(player, "server")
end)

-- Re-shows the form for all players with the form open
my_gui:update_where(function() return true end)

Inside an on_event handler, you can use return true instead.

gui.Button{
    label = "Update form",
    on_event = function(player, ctx)
        return true
    end,
}

If you're using a form as a HUD, you must call form:show_hud to update it.
