    Flow Unofficial Documentation

    Flow is an experimental layout manager and formspec API replacement for Luanti (formerly Minetest). Describe your menu, and flow handles the rest. Vaguely inspired by Flutter and GTK.

    Luanti's built-in menu format (inventories, chests, dialogs, ...) is formspec, consisting of one long string of buttons, text fields, and inventory slots. With formspec, you have to manually place every element by position and size, consult official docs in case of the many gotchas, and there's no reasonable way to write an LSP for it.

    Flow lets you describe the same menu with plain Lua tables, positions and sizes everything for you, and generates the formspec behind the scenes. You never have to write one. And if you like using modern IDE features, you will now actually have direct access to definitions from the editor (LuaCATS annotations are included).

    Terms Used in This Documentation

    Term Meaning
    Form A menu made with flow, created with flow.make_gui() and shown with form:show(), see Getting Started. This documentation does not call it a "gui".
    Formspec Luanti's own text format for menus. Flow generates formspecs for you.
    Element One part of a form, such as a label, a button, or a box. Elements are made with the functions in flow.widgets (the name of that table is the only place "widget" is used), see Functional Elements and Layout Elements.
    Build function The function you pass to flow.make_gui(). It returns the elements of the form and is called every time the form is drawn, see Getting Started.
    Root element The element that the build function returns, which holds everything else in the form.
    Container An element that holds other elements. gui.Container is the one whose elements you place yourself with x and y, see Manual Positioning.
    Layout element An element that arranges the elements inside it, such as gui.VBox, gui.HBox, and gui.Stack, see Layout Elements.
    Flow The mod. gui.Flow (written with the gui. prefix) is an element of the mod that wraps its children onto new rows.
    ctx The context table of a form, see Getting Started.

    Features

    Layouting

    • Automatic placement. Flow works out every position, so there's no arithmetic to redo when you add one button.
    • Comprehensive layout elements. Nest HBox and VBox containers and they line up on their own. Scrolling, paging, stacking, wrapping, and flexible spacing are covered too. And yes, also manual placement using Container.
    • Automatic sizing. Labels, checkboxes, buttons, text fields, password fields, text areas, drop-downs, text lists, and vertical labels size themselves. See Sizes.
    • Room to grow. Set expand = true and an element fills any spare space, see Parameters Shared by All Elements.
    • Translation-friendly. Elements sized from their label grow or shrink to fit longer text1.

    Other Features

    • No form names. They still exist internally, but you never have to deal with them.
    • No state bookkeeping. Flow remembers the values of fields, scrollbars, checkboxes, and the like across redraws, and reapplies them for you, see Names and Values.
    • Built-in debugging. The inspector mod helps you develop and debug forms.
    • Safer input handling. Flow mitigates some common formspec input security issues. See Security.

    Limitations

    • This mod doesn't support all of the features that regular formspecs do. See Unsupported Features for a list.

    Security

    Flow ignores potentially malicious formspec input from clients, such as buttons or fields that haven't been shown to the client, out-of-bounds dropdown selections, and newlines in Field elements (where it's impossible to enter a newline without pasting it in). See Security for the full list of what flow checks and what you still need to check yourself.

    Other Documentation

    The official documentation is available at https://luk3yx.gitlab.io/minetest-flow/. Some code snippets have a "run" button which will open them in a web-based playground.

    Playground limitations

    Not all snippets will work properly in the playground, as it doesn't support all formspec elements. See Unsupported Features.

    1. This is an estimate, not a measurement. The real size of a label depends on the client's font, DPI, window size, and formspec scaling settings, and Luanti gives mods no way to measure text. Flow assumes 0.21 slots per character (UTF-8 characters, not bytes, counting the longest line) and 0.4 slots per line of height, scaled by any *1.5-style font_size style. It ignores the font. If the estimate is off for your text, set w, h, or min_w yourself. ↩
