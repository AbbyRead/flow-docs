    Functional Elements

    gui.AnimatedImage

    Shows an image that plays an animation. The texture must contain every frame stacked on top of each other (the first frame at the top), with all frames the same size, like the frames of an animated node texture. So a texture with 3 frames of 16x16 pixels is 16 pixels wide and 48 pixels high. w and h are the size of one displayed frame, and the picture is scaled to that size.

    middle_* parameters turn on nine-slice drawing, see Nine-Slice Images. The cuts are measured in pixels of one frame.

    The examples below use a texture with three frames, a red, a green, and a blue square with a white border. It is made with texture modifiers ([fill), so no file is needed: the first [fill makes a white 16x48 image, and each one after it paints a 12x12 square into one of the frames. You can use any texture that has the frames stacked in the same way.

    Example

    gui.AnimatedImage {
    w = 2,
    h = 2,

    -- Only useful for styling.
    name = "my_animated_image", -- Optional

    -- Texture that contains all frames, stacked from top to bottom.
    -- This one is 16 pixels wide and 48 high: three frames of 16x16.
    texture_name = "[fill:16x48:white^[fill:12x12:2,2:#E74C3C"
        .. "^[fill:12x12:2,18:#2ECC71^[fill:12x12:2,34:#3498DB",

    -- Number of frames in the texture.
    frame_count = 3,

    -- Milliseconds each frame is shown for. 0 means no animation.
    frame_duration = 500,

    -- Frame to start on, the first frame is 1. Default 1.
    -- This one starts on the green frame.
    frame_start = 2, -- Optional

    -- Nine-slice cuts, in pixels of one frame. Also optional: middle_y,
    -- middle_x2 and middle_y2, see the live example below.
    middle_x = 2, -- Optional
}

    Dynamic Example

    gui.AnimatedImage requires a vertically stacked frame strip (normally a PNG file). To keep this example self-contained, it uses Luanti texture modifiers instead:

    • [fill:16x48:white: Creates a 16x48 white base image.
    • ^: Chains the next modifier to apply over it.
    • [fill:12x12:2,2:#E74C3C: Paints a 12x12 red square at position (2, 2).

    Three 12x12 squares (red, green, blue) are stacked 16 pixels apart at \(y = 2\), \(18\), and \(34\), leaving a 2-pixel white border. (Refer to the Luanti API documentation for more on texture modifiers.)

    The example renders three views side-by-side:

    1. The full texture strip (gui.Image).
    2. The cycling animation (gui.AnimatedImage).
    3. A nine-slice stretched version (middle_x = 2).

    (Note: Set frame_duration = 0 to pause the animation on a specific frame using frame_start.)

    -- Three 16x16 frames stacked into one 16x48 texture (red, green, blue).
-- This is a Luanti texture modifier string, not something flow-specific.
-- With a real file you would just write: local FRAMES_TEXTURE = "my_frames.png"
local FRAMES_TEXTURE = "[fill:16x48:white^[fill:12x12:2,2:#E74C3C"
    .. "^[fill:12x12:2,18:#2ECC71^[fill:12x12:2,34:#3498DB"

local form = flow.make_gui(function(player, ctx)
    return gui.HBox {
        gui.VBox {
            gui.Label { label = "The texture" },
            gui.Image { w = 1, h = 3, texture_name = FRAMES_TEXTURE },
        },
        gui.VBox {
            gui.Label { label = "One frame at a time" },
            gui.AnimatedImage {
                w = 3, h = 3,
                texture_name = FRAMES_TEXTURE,
                frame_count = 3,
                frame_duration = 500,
            },
        },
        gui.VBox {
            gui.Label { label = "Nine-slice (middle_x = 2)" },
            gui.AnimatedImage {
                w = 4, h = 2,
                texture_name = FRAMES_TEXTURE,
                frame_count = 3,
                frame_duration = 500,
                middle_x = 2,
            },
        },
    }
end)

    gui.Background

    Draws a picture behind everything else in the form: all backgrounds are drawn before any other element, whatever order they are in. The picture (texture_name) is stretched to w by h. If auto_clip is true, it is cut off at the edge of the form instead and w and h are ignored.

    You usually do not need this element, set bgimg on a container or the root element instead (see Padding). Inside a gui.Stack, a gui.ScrollableVBox, or an embedded form, flow draws backgrounds without auto_clip as ordinary images.

    Example

    gui.Background {
    w = 6,
    h = 3,

    -- Picture to draw. This one is a white border around a blue square,
    -- made with texture modifiers so that no file is needed.
    texture_name = "[fill:16x16:white^[fill:12x12:2,2:#336699",

    -- Cut off at the form edge, ignore w and h.
    auto_clip = false, -- Optional
}

    Live Example

    A background is only useful when something is drawn on top of it, so this example puts one in a gui.Container (see Manual Positioning) together with a button. The background comes after the button in the list, but it is still drawn behind it.

    local form = flow.make_gui(function(player, ctx)
    return gui.VBox {
        gui.Container {
            w = 6, h = 3,
            { type = "button", x = 1.5, y = 1, w = 3, h = 1, label = "In front" },
            {
                type = "background",
                x = 0, y = 0, w = 6, h = 3,
                texture_name = "[fill:16x16:white^[fill:12x12:2,2:#336699",
            },
        },
    }
end)

    gui.Background9

    Like gui.Background, but the picture is drawn as a nine-slice so that it can be stretched to any size without distorting its corners.

    Example

    gui.Background9 {
    w = 6,
    h = 3,

    -- Picture to draw. This one is a white border around a blue square,
    -- made with texture modifiers so that no file is needed.
    texture_name = "[fill:16x16:white^[fill:12x12:2,2:#336699",

    -- Cut off at the form edge, ignore w and h.
    auto_clip = false,

    -- Nine-slice cut, see "Nine-slice images". The border of the texture is
    -- 2 pixels wide, so cut 2 pixels from every side.
    middle_x = 2,
    middle_y = 2, -- Optional
    middle_x2 = -2, -- Optional
    middle_y2 = -2, -- Optional
}

    Live Example

    Both backgrounds use the same texture and are the same size. The left one is a plain gui.Background that stretches the whole picture, so its border gets thick and blurry. The right one is a gui.Background9 with middle_x = 2, so only the middle is stretched and the border stays sharp.

    local FRAME = "[fill:16x16:white^[fill:12x12:2,2:#336699"

local form = flow.make_gui(function(player, ctx)
    return gui.HBox {
        gui.Container {
            w = 5, h = 3,
            { type = "label", x = 0.5, y = 1.5, label = "Background" },
            { type = "background", x = 0, y = 0, w = 5, h = 3, texture_name = FRAME },
        },
        gui.Container {
            w = 5, h = 3,
            { type = "label", x = 0.5, y = 1.5, label = "Background9" },
            {
                type = "background9",
                x = 0, y = 0, w = 5, h = 3,
                texture_name = FRAME,
                middle_x = 2,
            },
        },
    }
end)

    gui.Bgcolor

    Sets the colors behind the form. This does the same thing as the bgcolor, fbgcolor, and bg_fullscreen options of the root element, which are explained in Experimental Features and are easier to use. fullscreen can be false, true, "both", or "neither".

    Example

    gui.VBox {
    gui.Bgcolor {
        -- Background color of the form.
        bgcolor = "#336699",

        -- false, true, "both", or "neither".
        fullscreen = false, -- Optional

        -- Color of the area behind the form.
        fbgcolor = "#00000080", -- Optional
    },

    gui.Label { label = "The form has a blue background." },
}

    Live Example

    Pick a color to change the background of the form.

    local form = flow.make_gui(function(player, ctx)
    return gui.VBox {
        -- Use the picked color (the first item before anything is picked).
        gui.Bgcolor { bgcolor = ctx.form.color or "red" },

        gui.Label { label = "Pick a background color:" },
        gui.Dropdown {
            name = "color",
            items = { "red", "green", "blue", "purple" },
        },
    }
end)

    gui.Box

    Draws a solid rectangle of one color. Boxes have no natural size, so give them a w and h.

    Unlike everywhere else, a hexadecimal color without an alpha value ("#RGB" or "#RRGGBB") is drawn with an alpha of 8C (140 out of 255, about 55% opaque) here. Add the alpha value ("#FF0000FF") to make it opaque. Color names such as "red" are not affected and are opaque unless you add an alpha value ("red#80"). Flow also draws the bgcolor of gui.HBox, gui.VBox, and other containers with a box, so the same applies to it.

    Example

    gui.Box {
    w = 1,
    h = 2,

    -- Fill color.
    color = "#FF0000",
}

    Opaque and Translucent Colors

    These four boxes all use red, written in different ways. The first and last ones are translucent and let the background of the form show through, and the other two are fully opaque:

    gui.HBox {
    -- #RRGGBB gets an alpha of 8C here, so this one is translucent.
    gui.Box { w = 1, h = 2, color = "#FF0000" },

    -- Add the alpha value to make it opaque.
    gui.Box { w = 1, h = 2, color = "#FF0000FF" },

    -- Color names are opaque unless you add an alpha value.
    gui.Box { w = 1, h = 2, color = "red" },

    -- This one has an alpha value of 80 (about half).
    gui.Box { w = 1, h = 2, color = "red#80" },
}

    gui.Button

    A clickable button showing label. Your on_event function is called when it is clicked. If you do not set w and h, the button is sized to fit the label (but never smaller than 1.6 by 0.8).

    Buttons do not store a value in ctx.form.

    Example

    gui.Button {
    w = 6, -- Optional
    h = 2, -- Optional
    name = "my_button", -- Optional
    label = "Hello world!", -- Optional
}

    gui.ButtonExit

    A button that closes the form when it is clicked. Your on_event function is still called before the form closes. In all other respects it works like gui.Button.

    Example

    gui.ButtonExit {
    w = 6, -- Optional
    h = 2, -- Optional
    name = "my_button_exit", -- Optional
    label = "Hello world!", -- Optional
}

    gui.ButtonURL

    A button that, when clicked, offers the player the choice of opening url in their web browser. url must start with http:// or https://. Your on_event function is also called. In all other respects it works like gui.Button.

    Example

    gui.ButtonURL {
    w = 6, -- Optional
    h = 2, -- Optional
    name = "my_button_url", -- Optional
    label = "Hello world!", -- Optional

    -- Web address to offer to open.
    url = "https://example.com",
}

    gui.ButtonUrlExit

    Like gui.ButtonURL, but the form also closes when the button is clicked. Unlike gui.ButtonURL, it does not get a size from its label, so w and h are required.

    Example

    gui.ButtonUrlExit {
    w = 6,
    h = 2,
    name = "my_button_url_exit", -- Optional
    label = "Hello world!", -- Optional

    -- Web address to offer to open.
    url = "https://example.com",
}

    gui.Checkbox

    A tick box with a text label. selected sets whether it starts ticked. If you give it a name, ctx.form[name] is true or false and is updated as soon as the player ticks or unticks it.

    Checkboxes are sized automatically and do not accept w or h.

    Example

    gui.Checkbox {
    name = "my_checkbox", -- Optional
    label = "Hello world!", -- Optional
    selected = true, -- Optional
}

    gui.Dropdown

    A drop-down list that shows the currently selected item and lets the player pick another one from items (a list of strings). selected_idx is the number of the item that is selected at first (the first item is 1).

    ctx.form[name] is the text of the selected item. If index_event = true it is the number of the selected item instead, which is easier to work with when two items have the same text or when the text is translated.

    If you do not set w and h, the dropdown is sized to fit its longest item (but never smaller than 2 by 0.8). Item text cannot be coloured.

    Example

    gui.Dropdown {
    w = 4, -- Optional
    h = 0.8, -- Optional
    name = "my_dropdown", -- Optional

    -- List of choices.
    items = { "Apple", "Banana", "Cherry" },

    -- Number of the item selected at first.
    selected_idx = 2, -- Optional

    -- Store the item number in ctx.form instead of its text.
    index_event = false, -- Optional
}

    gui.Field

    A single-line text box. label, if set, is shown above the box (flow leaves room for it automatically). default is the text it starts with.

    ctx.form[name] is the text in the box. Newlines and other control characters are removed from it, but tabs are kept (a player can only get a newline into a field by pasting). See Security for the exact rules. The text is sent to the server when the player presses a button or Enter. To react to Enter, see Handling Enter Keypresses in Fields.

    If you do not set w and h, the field is sized to fit its default text and label (but never smaller than 3 by 0.8).

    Example

    gui.Field {
    w = 6, -- Optional
    h = 2, -- Optional
    name = "my_field", -- Optional
    label = "Hello world!", -- Optional

    -- Text the field starts with.
    default = "Hello world!", -- Optional

    -- Called when the player presses Enter.
    on_key_enter = function(player, ctx) end, -- Optional

    -- Close the form on Enter. Default false.
    close_on_enter = false, -- Optional

    -- Make "Done" on the mobile on-screen keyboard act like Enter.
    enter_after_edit = false, -- Optional
}

    gui.FieldCloseOnEnter

    Sets whether pressing Enter in the field with this name closes the form. You normally do not need this element, as gui.Field has a close_on_enter parameter (and by default Enter does not close the form).

    Example

    gui.VBox {
    gui.Field { name = "my_field_close_on_enter", label = "Press Enter to close the form" },

    gui.FieldCloseOnEnter {
        -- Name of the field.
        name = "my_field_close_on_enter",
        close_on_enter = true,
    },
}

    Live Example

    Type something and press Enter. The label shows the text that was sent. While the checkbox is ticked, Enter also closes the form.

    local form = flow.make_gui(function(player, ctx)
    return gui.VBox {
        gui.Field { name = "note", label = "Type something, then press Enter:" },

        -- Close on Enter only while the box is ticked.
        gui.FieldCloseOnEnter {
            name = "note",
            close_on_enter = ctx.form.close or false,
        },

        gui.Checkbox { name = "close", label = "Close the form on Enter" },
        gui.Label { label = "Last text sent: " .. (ctx.form.note or "") },
    }
end)

    gui.FieldEnterAfterEdit

    Experimental, and only affects Android. If enter_after_edit is true, pressing "Done" in the text input dialog of the field with this name counts as pressing Enter. You normally do not need this element, as gui.Field has an enter_after_edit parameter.

    Example

    gui.VBox {
    gui.Field { name = "my_field_enter_after_edit", label = "Edit me, then press Done" },

    gui.FieldEnterAfterEdit {
        -- Name of the field.
        name = "my_field_enter_after_edit",
        enter_after_edit = true,
    },
}

    Live Example

    Press Enter in the field and the counter goes up. On Android, tick the checkbox to make "Done" in the on-screen keyboard count as Enter too.

    local form = flow.make_gui(function(player, ctx)
    return gui.VBox {
        gui.Field {
            name = "msg",
            label = "Edit, then press Enter (or Done on Android):",
            on_key_enter = function(player, ctx)
                ctx.enters = (ctx.enters or 0) + 1
                return true -- redraw
            end,
        },

        -- Count "Done" as Enter only while the box is ticked.
        gui.FieldEnterAfterEdit {
            name = "msg",
            enter_after_edit = ctx.form.after_edit or false,
        },

        gui.Checkbox { name = "after_edit", label = "Done counts as Enter (Android)" },
        gui.Label { label = "Enter pressed " .. (ctx.enters or 0) .. " times" },
    }
end)

    gui.Hypertext

    Shows text that can be formatted (bold, colors, different sizes, images, ...) and can contain clickable links. The text is written in a small HTML-like language, which is described in Hypertext Markup. w and h are the size of the area that the text is wrapped to fit in.

    If the markup contains <action name=...> links, ctx.form[name] is set to "action:" followed by the action name when the player clicks one. This behaviour is experimental and may change.

    Example

    gui.Hypertext {
    w = 6,
    h = 2,

    -- Receives the clicked action, see above.
    name = "my_hypertext", -- Optional

    -- Formatted text, see "Hypertext markup".
    text = "<big>Hello</big> <b>bold</b> <i>italic</i> " ..
        "<style color='red'>red</style> world!",
}

    gui.Image

    Shows a picture, stretched to fit w by h. If you want to use one small texture for pictures of many sizes, use the middle_* parameters, see Nine-Slice Images.

    Example

    gui.Image {
    w = 4,
    h = 2,

    -- Texture to draw. This one is a white border around a blue square,
    -- made with texture modifiers so that no file is needed.
    texture_name = "[fill:16x16:white^[fill:12x12:2,2:#336699",

    -- Nine-slice cuts, in pixels of the texture. The border is 2 pixels
    -- wide, so these keep it the same width however big the image is.
    middle_x = 2, -- Optional
    middle_y = 2, -- Optional
    middle_x2 = -2, -- Optional
    middle_y2 = -2, -- Optional
}

    gui.ImageButton

    A button that is drawn as a picture instead of the usual button face. The picture (texture_name) is stretched to w by h, and label is drawn on top of it. It works like gui.Button otherwise.

    • noclip: Allow the button to be drawn outside the form's area.
    • drawborder: Draw the normal button border around the picture.
    • pressed_texture_name: Picture to show while the button is held down.

    Example

    gui.ImageButton {
    w = 6,
    h = 2,

    -- Picture to draw as the button. This one is a blue square, made with
    -- a texture modifier so that no file is needed.
    texture_name = "[fill:16x16:#3498DB",
    name = "my_image_button", -- Optional
    label = "Hello world!", -- Optional
    noclip = false, -- Optional
    drawborder = false, -- Optional

    -- Picture to show while the button is held down (a red square).
    pressed_texture_name = "[fill:16x16:#E74C3C", -- Optional
}

    gui.ImageButtonExit

    Like gui.ImageButton, but the form also closes when the button is clicked.

    Example

    gui.ImageButtonExit {
    w = 6,
    h = 2,

    -- Picture to draw as the button. This one is a blue square, made with
    -- a texture modifier so that no file is needed.
    texture_name = "[fill:16x16:#3498DB",
    name = "my_image_button_exit", -- Optional
    label = "Hello world!", -- Optional
    noclip = false, -- Optional
    drawborder = false, -- Optional

    -- Picture to show while the button is held down (a red square).
    pressed_texture_name = "[fill:16x16:#E74C3C", -- Optional
}

    gui.ItemImage

    Shows the picture that is used for an item or node in inventories (item_name, such as "unifieddyes:colorium"), stretched to fit w by h.

    Example

    gui.ItemImage {
    w = 2,
    h = 2,

    -- Registered item or node name.
    item_name = "unifieddyes:colorium",
}

    gui.ItemImageButton

    A button that shows the inventory picture of an item or node (item_name). By default, the item's description is shown as a tooltip when the player hovers over the button, which you can replace with the tooltip parameter. It works like gui.Button otherwise.

    Give every item image button its own unique name, otherwise its tooltip may not work.

    Example

    gui.ItemImageButton {
    w = 3,
    h = 2,

    -- Registered item or node name.
    item_name = "unifieddyes:colorium",
    name = "my_item_image_button", -- Optional
    label = "Hello world!", -- Optional
}

    gui.Label

    Shows text. Labels do not wrap long lines automatically: use \n to start a new line and do not use labels for long paragraphs. For those, use gui.Hypertext, or a gui.Textarea without a name (which wraps its text and gets a scrollbar if the text is too long).

    Labels are sized to fit their text, and flow ignores color escape sequences when it estimates the width. To make the text bigger or smaller, use the font_size style (for example style = {font_size = "*2"}), see Styling.

    Example

    gui.Label {
    label = "Hello world!",
}

    gui.List

    Shows a grid of inventory slots, with the items of one inventory list in it. This is how you show the player's inventory, a chest, a furnace's input slots, and so on.

    • inventory_location: Which inventory to show. Common values are "current_player" (the inventory of the player who has the form open), "nodemeta:X,Y,Z" (the inventory of the node at that position, for example "nodemeta:10,5,-3"), and "detached:name" (a detached inventory). "player:name" is the inventory of a specific player and is only ever sent to that player.
    • list_name: The name of the list inside that inventory, such as "main" or "craft".
    • w and h: How many slots wide and high to draw (whole numbers).

    Slots are filled from left to right, then top to bottom, and the player can move items in and out of them. The list is only shown if the inventory has been sent to the player's client. Only as many slots as the inventory list has are drawn, even if w times h is larger.

    Each slot is 1 by 1, with 0.25 between slots, so a list that is 8 slots wide and 4 high is 9.75 by 4.75 big. To change the slot size or spacing, use the size and spacing styles, see Styling.

    Example

    gui.List {
    -- Which inventory to show.
    inventory_location = "current_player",

    -- Which list in that inventory to show.
    list_name = "main",
    w = 4,
    h = 2,

    -- Index of the first slot to draw. Unlike most numbers here, this starts
    -- at 0. Default 0.
    starting_item_index = 3, -- Optional
}

    gui.Listring

    Sets where items go when the player shift-clicks them. A ring is an ordered list of inventory lists that Luanti keeps for the form, which starts out empty. Every gui.Listring{inventory_location = ..., list_name = ...} adds one list to the end of the ring. When the player shift-clicks an item in a list that is in the ring, the item is sent to the next list in the ring. Lists that are not in the ring keep Luanti's default shift-click behavior.

    For example, after the two gui.Listring elements in the example below the ring is main, then craft. Shift-clicking an item in main sends it to craft, and shift-clicking an item in craft sends it to main.

    A list can be added to the ring more than once. When the player shift-clicks an item, Luanti looks for the first entry in the ring that is the list the item is in, and sends the item to the entry after it (the first entry comes after the last one). Later entries of the same list are only destinations: they never decide where items from that list go.

    For example, shift-clicking in a ring of main, craft, main sends items from main to craft and items from craft to main, the same as a ring of main and craft. Repeating a list is useful when several lists should send to the same one. In a ring of main, craft, main, output, items from main still go to craft, items from craft go to the second main, and items from output go to the first main (the ring wraps around), so both craft and output send to main.

    gui.Listring{} with no parameters adds the last two gui.List elements that came before it. It is invisible and takes up no space.

    Example

    gui.VBox {
    gui.List { inventory_location = "current_player", list_name = "main", w = 4, h = 1 },
    gui.List { inventory_location = "current_player", list_name = "craft", w = 3, h = 1 },

    -- Shift-clicking an item in one of the lists above moves it to the
    -- other one, because both of them are in the ring.
    gui.Listring {
        -- Same as for gui.List.
        inventory_location = "current_player", -- Optional

        -- Same as for gui.List.
        list_name = "main", -- Optional
    },
    gui.Listring {
        inventory_location = "current_player",
        list_name = "craft",
    },
}

    Live Example

    Shift-click an item in either list to send it to the other one. Untick the checkbox to remove the ring and shift-click goes back to Luanti's default.

    gui.ScrollContainer

    An area of a fixed size that clips the elements inside it and moves them when a scrollbar is moved. You usually want gui.ScrollableVBox instead, which does all of this for you. The elements inside are positioned by hand with x and y, like in gui.Container.

    • w and h: The size of the visible area.
    • scrollbar_name: The name of the gui.Scrollbar that controls the area. You need to add that scrollbar yourself.
    • orientation: "vertical" (the default) or "horizontal".
    • scroll_factor: How far the contents move for each step of the scrollbar's value. Default 0.1. It cannot be negative.

    Flow cannot work out the range of the scrollbar for you here. Set max and thumbsize with gui.ScrollbarOptions before the scrollbar:

    • max is the height that is hidden divided by scroll_factor. The hidden height is the height of the contents minus the h of the container. The scrollbar then runs from 0 to max, and each step moves the contents by scroll_factor.
    • thumbsize is the size of the draggable thumb, counted in the same steps. Luanti defines it as the number of steps the thumb spans out of the whole range, so the thumb is as large a fraction of the track as the visible part is of the contents: thumbsize = max * h / content_height.

    Both must be whole numbers, so round the result.

    Example

    gui.HBox {
    gui.ScrollContainer {
        w = 4, h = 3,
        scrollbar_name = "my_scrollbar",
        orientation = "vertical",
        { type = "label", x = 0, y = 0.5, label = "Top" },
        { type = "label", x = 0, y = 7.5, label = "Bottom" },
    },

    -- The contents are 8 high and 3 are visible, so 5 are hidden. This
    -- is 50 scroll steps of 0.1 each (max = 5 / 0.1).
    -- thumbsize = 50 * 3 / 8 = 18.75, rounded to 19.
    gui.ScrollbarOptions { opts = { max = "50", thumbsize = "19" } },
    gui.Scrollbar {
        w = 0.5, h = 3,
        orientation = "vertical",
        name = "my_scrollbar",
    },
}

    gui.Scrollbar

    A slider that the player can drag. ctx.form[name] is its position, a whole number from min to max (by default 0 to 1000, change them with gui.ScrollbarOptions before the scrollbar). value is the position it starts at, and orientation is "vertical" or "horizontal". Use it with a gui.ScrollContainer, or by itself as a slider.

    Example

    gui.Scrollbar {
    w = 0.6,
    h = 4,

    -- "vertical" or "horizontal".
    orientation = "vertical",
    name = "my_scrollbar", -- Optional

    -- Starting position, from 0 to 1000 by default.
    value = 300, -- Optional
}

    Do not use the scrollbar_bg, slider, arrow_up, and arrow_down texture parameters: Luanti has no such parameters, and on Luanti 5.8 and newer a scrollbar that sets any of them is not shown at all. See Scrollbar Textures Do Not Work.

    gui.ScrollbarOptions

    Sets the options of the gui.Scrollbar elements that come after it. It is invisible and takes up no space. opts is a table with any of these options, all values are strings that contain whole numbers (except arrows):

    • min: The smallest value (default 0).
    • max: The largest value (default 1000). If it is the same as min, the scrollbar is disabled.
    • smallstep: How much the value changes when an arrow is clicked or the mouse wheel is scrolled (default 10). A negative number resets it to 10.
    • largestep: How much the value changes for Page Up and Page Down (default 100). A negative number resets it to 100.
    • thumbsize: The size of the thumb (the part that is dragged), counted in values out of the range of the scrollbar. For a scrollbar from 1 to 100, a thumbsize of 10 makes the thumb a tenth of the scrollbar long. If it is zero or less, it is reset to 1.
    • arrows: "show" or "hide" the arrow buttons. "default" hides them if the scrollbar gets too small, and shows them otherwise.

    Example

    gui.VBox {
    -- Changes the scrollbar below: it goes from 0 to 100, has no arrows, and
    -- moves in steps of 5.
    gui.ScrollbarOptions {
        opts = { min = "0", max = "100", smallstep = "5", arrows = "hide" },
    },

    gui.Scrollbar {
        name = "my_scrollbar",
        orientation = "horizontal",
        w = 6, h = 0.6,
        value = 50,
    },
}

    Live Example

    Drag the scrollbar or click the arrows. The value is limited to 0-100 and changes in steps of 5.

    gui.Table

    A table with rows and columns that scrolls if it has too many rows. The player can select one row, and ctx.form[name] is the number of the selected row (the first row is 1). selected_idx is the row that is selected at first.

    cells is one flat list with the text of every cell, going left to right along each row and then down to the next row. The number of columns comes from gui.TableColumns (the default is one text column). Put gui.TableColumns and gui.TableOptions before the table, as they only affect the table that comes after them. They do not take up any space.

    Tables have no natural size, so you must give them a w and h.

    Example

    gui.Table {
    w = 4,
    h = 2,
    name = "my_table", -- Optional

    -- Text of every cell, row by row. There is one column by default, so
    -- this is four rows.
    cells = { "Alice", "Bob", "Carol", "Dave" },

    -- Row selected at first, the first row is 1.
    selected_idx = 3, -- Optional
}

    Example With Columns and Options

    This example uses gui.TableColumns to set the width and alignment of two text columns and gui.TableOptions to change the color of the selected row. Both are explained below.

    gui.VBox {
    gui.TableColumns {
        tablecolumns = {
            { type = "text", opts = { width = "8" } },
            { type = "text", opts = { align = "right" } },
        },
    },
    gui.TableOptions {
        opts = { highlight = "#335577" },
    },
    gui.Table {
        w = 10, h = 4,
        name = "scores",
        cells = {
            "Alice", "10",
            "Bob", "7",
        },
    },
}

    gui.TableColumns

    Sets the columns of the gui.Table that follows it. tablecolumns is a list with one {type = ..., opts = {...}} entry for each column, from left to right. type is one of:

    • "text": Show the cell contents as text.
    • "image": The cell contents are a number that picks an image, which you set with the options ["0"] = "texture.png", ["1"] = "other.png", and so on (the numbers do not have to be consecutive). Empty cells and cells that are not numbers use image 0. Images are scaled down to fit the height of the row if necessary.
    • "color": The cell contents are a color that is used for the text of the next column(s). Use the span option to set how many columns it affects (default: all remaining columns).
    • "indent": The cell contents are a number that sets how far the next column is indented.
    • "tree": Like "indent", but the player can open and close the indented rows, like in a file browser.

    opts is a table of options, all values are strings. width and padding are measured in "em" units (relative to the font size), unlike most other sizes in flow, which are in slot units:

    • align: For text and image columns, where the content goes in the cell: "left" (default), "center", "right", or "inline".
    • width: For text and image columns, the minimum width, in "em" units (relative to the font size, default 0). For indent and tree columns, how far each level is indented (default 1.5).
    • padding: Space to the left of the column, in "em" units (default 0.5, or 0 for indent columns).
    • tooltip: Text to show when hovering over the column.
    • span: For color columns, how many of the following columns the color affects (default: all remaining columns).

    Example

    See Example With Columns and Options under gui.Table, which uses the same two text columns. The live example below also uses a color column. For indent and tree columns, see Example With Indent and Tree Columns.

    Live Example

    Pick an alignment for the last column and select a row. The middle column colors the text of the last one.

    local names = { "Alice", "Bob", "Carol" }

local form = flow.make_gui(function(player, ctx)
    return gui.VBox {
        gui.Dropdown { name = "align", items = { "left", "center", "right", "inline" } },

        -- Set the columns of the table below.
        gui.TableColumns {
            tablecolumns = {
                { type = "text", opts = { width = "8" } },
                { type = "color", opts = {} },
                { type = "text", opts = { align = ctx.form.align or "left" } },
            },
        },
        gui.Table {
            w = 6, h = 3,
            name = "scores",
            cells = {
                "Alice", "#66FF66", "10",
                "Bob", "#FFFF66", "7",
                "Carol", "#FF6666", "3",
            },
        },

        gui.Label { label = "Selected: " .. names[ctx.form.scores or 1] },
    }
end)

    Example With Indent and Tree Columns

    An "indent" or "tree" column takes one cell in every row, like any other column, but the cell is not shown. It holds the level of the row: "0" for the leftmost level, "1" for the next one, and so on (a negative number counts as 0). The column after it is moved to the right by the level times the width option of the indent or tree column, so put the text you want to show in that next column.

    gui.VBox {
    gui.TableColumns {
        tablecolumns = {
            -- The level of each row. It is not shown.
            { type = "tree", opts = {} },
            -- The text of each row.
            { type = "text", opts = { width = "8" } },
        },
    },
    gui.TableOptions {
        -- Open the rows of level 0 at first.
        opts = { opendepth = "1" },
    },
    gui.Table {
        w = 5, h = 3,
        name = "files",
        cells = {
            "0", "Fruit",
            "1", "Apple",
            "1", "Banana",
            "0", "Vegetables",
            "1", "Carrot",
        },
    },
}

    Each row has two cells: its level, then its text. Apple and Banana are one level deeper than Fruit, so they are indented and belong to it, and Carrot belongs to Vegetables. A row is the parent of the rows right below it that are deeper than it.

    With "tree", a parent row shows a - (open) or + (closed) before its text, and rows without children show no sign. The player clicks the sign, or double-clicks the row, to open or close the rows below it. Clicking the sign does not select the row and sends nothing to the server. opendepth = "1" in gui.TableOptions opens the rows of level 0 at first, so the rows of level 1 are visible. Without it, only the rows of level 0 (Fruit and Vegetables) are visible until the player opens them. The selected row in ctx.form.files is the position of the row in cells, so Carrot is 5 even when the rows above it are closed.

    With "indent", the rows are indented in the same way, but there is no sign and every row is always visible.

    gui.TableOptions

    Sets the appearance of the gui.Table that follows it. opts is a table with any of these options, all values are strings:

    • color: Default text color (default "#FFFFFF").
    • background: Background color of the table (default "#000000").
    • border: "true" or "false", whether to draw a border (default "true").
    • highlight: Background color of the selected row (default "#466432").
    • highlight_text: Text color of the selected row (default "#FFFFFF").
    • opendepth: How many levels of "tree" column rows are open at first. Rows deeper than this are collapsed (default "0"). See Example With Indent and Tree Columns.

    Example

    gui.VBox {
    gui.TableOptions {
        opts = {
            background = "#222222",
            highlight = "#335577",
            border = "false",
        },
    },

    gui.Table {
        w = 4, h = 2,
        name = "names",
        cells = { "Alice", "Bob", "Carol" },
        selected_idx = 2,
    },
}

    Live Example

    Pick a highlight color, select a row, and tick or untick the border.

    A list of text rows that scrolls if there are too many to fit. The player can select a row, and ctx.form[name] is the number of the selected row (the first row is 1). selected_idx is the row that is selected at first.

    listelems is the text of each row. To color a row, start it with #RRGGBB (six hexadecimal digits). To start a row with a literal #, write ##. If transparent is true, no background is drawn behind the list.

    Example

    gui.Textlist {

    name = "my_textlist", -- Optional

    -- Text of each row. The second row is orange because it starts with a
    -- color, and the third starts with a literal #.
    listelems = { "Plain row", "#FF8800Orange row", "##Hash row", "Last row" },

    -- Row selected at first, the first row is 1.
    selected_idx = 3, -- Optional

    -- Do not draw a background. Default false.
    transparent = false, -- Optional
}

    gui.Tooltip

    Sets the text that is shown when the player hovers over another element, and optionally the colors of that tooltip. gui_element_name is the name of that element. Put the tooltip after the element it belongs to. It is invisible and does not take up any space.

    If you only need to add some text, use the tooltip parameter on the element itself, see Tooltips.

    Example

    gui.VBox {
    gui.Button { name = "my_button", label = "Hover over me" },

    gui.Tooltip {
        -- Text to show.
        tooltip_text = "Hello world!",

        -- Background color of the tooltip.
        bgcolor = "#000000", -- Optional

        -- Text color of the tooltip.
        fontcolor = "#FFFF00", -- Optional

        -- Name of the element to attach to.
        gui_element_name = "my_button",
    },
}

    Example

    Hover over the button to see the tooltip. Click it and hover again: the text has changed.

    local form = flow.make_gui(function(player, ctx)
    return gui.VBox {
        gui.Button {
            name = "my_button",
            label = "Click me, then hover",
            on_event = function(player, ctx)
                ctx.clicks = (ctx.clicks or 0) + 1
                return true -- redraw
            end,
        },
        gui.Tooltip {
            gui_element_name = "my_button",
            tooltip_text = ("Clicked %d times"):format(ctx.clicks or 0),
            bgcolor = "#000000",
            fontcolor = "#FFFF00",
        },
    }
end)
