Styling forms

Styles change how elements look: their colors, images, fonts, and so on. A style is a set of properties such as bgcolor = "red", and which properties exist depends on the type of element. All of them are listed in the property reference below.

You can style a single element with the style field (the inline syntax), or style many elements at once with the gui.Style and gui.StyleType elements (see separate style elements).

Inline syntax

At the moment I suggest only using this syntax if your form won't look broken without the style - older versions of flow don't support this syntax, and I may make breaking changes to the sub-style syntax in the future.

You can add inline styles to elements with the style field:

gui.Button{
    label = "Test",
    style = {
        bgcolor = "red",

        -- You can style specific states of elements:
        {sel = "$hovered", bgcolor = "green"},

        -- Or a combination of states:
        {sel = "$hovered, $pressed", bgcolor = "blue"},
        {sel = "$hovered+pressed", bgcolor = "white"},
    },
}

The properties directly inside style always apply. A sel entry only applies while the element is in one of the listed states. Separate states with a comma to apply the style when any of them is active ("$hovered, $pressed"), or join them with + to apply it only when all of them are active at once ("$hovered+pressed").

If you need to style multiple elements, you can reuse the style table:

local my_style = {bgcolor = "red", {sel = "$hovered", bgcolor = "green"}}

local gui = flow.make_gui(function(player, ctx)
    return gui.VBox{
        gui.Button{label = "Styled button", style = my_style},
        gui.Button{label = "Unstyled button"},
        gui.Button{label = "Second styled button", style = my_style},
    }
end)

Note that this may inadvertently reset styles on subsequent elements if used on elements without a name. Luanti can only style unnamed elements by their type, so flow applies the style to every element of that type and then resets those properties to their defaults straight after the element. This also undoes any earlier gui.StyleType for the same properties. Give the element a name to avoid this.

Property values are normally strings, but flow also accepts numbers and booleans where a property needs one. Setting a property to an empty string (bgimg = "") resets it to its default value.

Separate style elements

Alternatively, you can use the gui.Style and gui.StyleType elements if you need to style a large group of elements or need to support older versions of flow:

gui.Style{
    selectors = {"btn1"},
    props = {
        bgimg = "button.png",
        border = false,
    }
},

gui.Button{
    name = "btn1",
    label = "Button",
},

The Style and StyleType elements are invisible and won't affect padding. They only affect the elements that come after them, so put them before the elements you want to style.

Warning: gui.Style and gui.StyleType do not support styles that change the element size, such as font_size for labels, buttons, and fields, and size/spacing for lists. Flow only sees these properties in the inline syntax, so use that for them.

Selectors and states

selectors is a list that says which elements the style applies to:

  • gui.Style selects elements by their name, so {"btn1"} styles the element with name = "btn1".
  • gui.StyleType selects elements by their type, so {"button"} styles every button that comes after it. The type is the element's name in lowercase with underscores between words, for example item_image_button for gui.ItemImageButton. Some types also style other types, see element types.
  • gui.StyleType also accepts "*", which selects every element.

A selector can end with a colon and one or more states to only style the element while it is in that state, such as "btn1:hovered" or "button:hovered+pressed" (+ means all of the states have to be active).

gui.StyleType{
    selectors = {"button", "image_button"},
    props = {textcolor = "yellow"},
},
gui.StyleType{
    selectors = {"button:hovered"},
    props = {bgcolor = "#336699"},
},

States

Every element has the default state, which is the same as not giving any state. Buttons (gui.Button, gui.ButtonExit, gui.ImageButton, gui.ItemImageButton) also have these states:

State Active when
focused The button has keyboard focus
hovered The mouse is over the button
pressed The button is being pressed

Property reference

Colors are described in Elements, and textures are image file names. A "2D vector" is written as a string such as "1,2". Properties that only list a type of element are not valid on other elements, and an unknown property is ignored.

All elements

Property Description
noclip Boolean. Set to true to let the element be drawn outside the area of the form. Default false.

Text properties

These properties change how text looks. font and font_size are valid on buttons, labels, fields, tables, and text lists. textcolor is valid on buttons, labels, fields, and tab headers, but not on tables and text lists. The sections below show which applies where.

Property Description
font Font type, a comma-separated list. Use at most one of normal (the default font) and mono (a font where every letter is the same width), and any of bold and italic. For example "mono,bold". If you only give bold or italic, normal is used. Default normal.
font_size Text size. "16" sets an absolute size, "+2" and "-2" make the text 2 points larger or smaller than the default, and "*1.5" multiplies the default size by 1.5 (like em in CSS). The default is the size the player has chosen in their settings.
textcolor Color of the text. Default white.

Flow can make room for bigger text in gui.Labels, buttons, and the default text of fields, but only if font_size starts with * and is set with the inline syntax (style = {font_size = "*2"}). Other values still change the text but not the size of the element. The labels above fields and checkboxes ignore font_size, and a gui.Label with a fixed h is positioned as if font_size was not set (this is deprecated).

Buttons

For gui.Button, gui.ButtonExit, gui.ImageButton, and gui.ItemImageButton. Buttons also support font, font_size, and textcolor.

Property Description
alpha Boolean. Whether to draw the transparent parts of bgimg. Default true.
bgcolor Color that tints the button.
bgimg Texture to use as the background of the button. Default none.
bgimg_middle Draws bgimg as a nine-slice. Written as a string in one of the formats "x", "x,y", or "x,y,x2,y2", which have the same meaning as middle_x, middle_y, middle_x2, and middle_y2. Also adds padding around the content of the button.
border Boolean. Whether to draw the bevelled button border. Set to false to hide it. Default true.
content_offset 2D vector that moves the content (text and image) of the button without resizing the button.
padding Space between the edges of the button and its content, as a rectangle written in the same formats as bgimg_middle. This value is relative to bgimg_middle.
sound A sound to play when the button is triggered.

gui.ImageButton has some more properties for the picture drawn on top of the button:

Property Description
fgimg The picture to draw. Default none. The texture_name and pressed_texture_name you give to the element take precedence over this.
fgimg_middle Draws fgimg as a nine-slice, like bgimg_middle.

Some older properties still work but are deprecated. Use states instead: bgcolor_hovered, bgcolor_pressed, bgimg_hovered, bgimg_pressed, fgimg_hovered, and fgimg_pressed. They work like bgcolor and bgimg but only apply while the button is hovered or pressed.

Fields and text areas

For gui.Field, gui.Pwdfield, and gui.Textarea. They also support font, font_size, and textcolor.

Property Description
border Boolean. Set to false to hide the background and border of the text box. Default true.
halign Horizontal alignment of the text: left (default), center, or right. Needs a recent version of Luanti (5.17 or newer), and flow may not be able to use it, see Features flow does not have.
valign Vertical alignment of the text: top (default), center, or bottom. Needs a recent version of Luanti (5.17 or newer). Only has an effect when all of the text fits inside the element. If the text is too long (and a gui.Textarea gets a scrollbar), it is always aligned to the top so that no text is cut off. It also does not work in gui.Field, but halign does.

Labels

For gui.Label and gui.Vertlabel: font, font_size, and textcolor.

Luanti also has halign and valign for labels, but they only apply to the area label, which flow does not have, so they do nothing here (see Features flow does not have).

Lists

For gui.List:

Property Description
size 2D vector. The size of each slot. Default "1,1".
spacing 2D vector. The space between slots. Default "0.25,0.25".

Flow uses these values to work out how big a list is, but it only understands whole numbers in them (such as "2,2" or "0,0").

Boxes

For gui.Box. These properties only take effect when the box has no color of its own. The colors, bordercolors, and borderwidths properties can have one, two, or four values separated by commas (like CSS borders):

  • One value, such as "#FF0": used for all corners or borders.
  • Two values, such as "red,#FFAAFF": for the colors, the top-left and bottom-right corners, then the top-right and bottom-left corners. For the widths, the top and bottom borders, then the left and right borders.
  • Four values, such as "blue,#A0F,green,#FFFA": starting with the top-left corner (or the top border) and going clockwise.
Property Description
colors Color of the corners of the box. Default black.
bordercolors Color of the borders of the box. Default black.
borderwidths Width of the borders in pixels, as a whole number. A negative width puts the border inside the box, a positive width puts it outside the box, and 0 draws no border. Default 0.

Models

For gui.Model:

Property Description
bgcolor Background color of the model area.

Other elements

Element Properties
gui.Checkbox sound: A sound to play when the box is ticked or unticked.
gui.Dropdown sound: A sound to play when a different item is selected.
gui.Tabheader sound: A sound to play when a different tab is selected. textcolor: Color of the tab text, default white.
gui.Table, gui.Textlist font and font_size. The colors of a table are set with gui.TableOptions.
gui.Image, gui.AnimatedImage, gui.ItemImage, gui.Scrollbar Only noclip.
