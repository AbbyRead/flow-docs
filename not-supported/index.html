Features flow does not have

Flow does not support everything that Luanti formspecs can do. This page lists what is missing, so you know before you look for it. Where there is a way to get a similar result, it is mentioned.

Missing elements

Formspec element What it does What to do instead
hypertip[] A tooltip that shows formatted text (see Hypertext markup). Flow tooltips only show plain text with the tooltip parameter or gui.Tooltip. The markup language can only be used in gui.Hypertext.
allow_close[] Stops the Escape key (and similar) from closing the form. Nothing. Players can always close a flow form. You can run code when they do with on_quit, but you cannot stop it.
listimages[] Pictures for the background of inventory slots. gui.Listcolors only sets colors.
label[x,y;w,h;text] A label that wraps long text inside a given size (an "area label"). gui.Textarea without a name, or gui.Hypertext. Because of this, the halign and valign styles do not do anything for gui.Label.
tooltip[x,y;w,h;...] A tooltip for an area instead of an element. The tooltip parameter of any element (flow uses the area of an element without a name for you). gui.Tooltip can only be attached to a named element.
field[name;label;default] A small form with a single field and an automatic "Proceed" button (for example for signs). Use a gui.Field and a gui.Button.

Missing parameters

  • Content padding of scroll containers. Luanti can work out the range of a scroll container's scrollbar for you, but flow's gui.ScrollContainer does not expose this, so you have to set the range yourself with gui.ScrollbarOptions. gui.ScrollableVBox already does this for you.
  • Node formspec inventory locations. The "current_node" inventory location refers to the node whose formspec is open. A flow form cannot be the formspec of a node, so use "nodemeta:X,Y,Z" to show a node's inventory instead.

Things flow does for you

These formspec elements exist, but flow generates them itself and you cannot write them:

  • size[]: The size of the form is worked out from the elements in it.
  • position[], anchor[], and padding[]: Use the window_position, window_anchor, and window_padding options of the root element, see Experimental features.
  • no_prepend[] and bgcolor[]: Use the no_prepend, bgcolor, fbgcolor, and bg_fullscreen options of the root element.
  • real_coordinates[]: Flow always uses the newer coordinate system, where there is no hidden padding or spacing between elements.
  • container_end[] and scroll_container_end[]: Elements inside gui.Container and gui.ScrollContainer are written inside the table.
  • formspec_version[]: Flow always uses formspec version 7.

Newer Luanti features

Because flow always uses formspec version 7 (Luanti 5.8), features that were added in newer versions may not work, even if the missing element or parameter is not listed above. This includes the area label (version 9), floating-point animation frames in gui.Model (version 10), and the halign and valign styles of fields and text areas (version 11). Formspec versions are described at the top of the Luanti API documentation.
